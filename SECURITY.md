# Security

Several packages here handle credentials and check what strangers send: keys, tokens, passkeys.
Please report a vulnerability privately, through GitHub's **Report a vulnerability** on this
repository's Security tab, not in a public issue.

Say which package and version, what an attacker can do, and how to reproduce it. You'll get an answer
within a few days; a fix is released as a new version of each affected package, with the report
credited in its CHANGELOG unless you'd rather not.

The latest version of each package receives fixes.
